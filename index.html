Google Sheet connection
Every entry you add is written straight to your Google Sheet (tab "Inventory Log"), so anyone using this same link sees the same list, and it survives closing the tab.

Connection:
1. Open a blank Google Sheet → Extensions → Apps Script
2. Copy all the code from the included file google_apps_script.gs, paste it in, then Deploy → New deployment → Web app, "Who has access" = Anyone
3. The connection URL is already built into this page, so no setup is needed when opening the hosted link.

To host this page online (so it works from any device, not just this one), drag this HTML file onto a static host such as GitHub Pages — ask if you'd like the exact steps.
